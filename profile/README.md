## 🚀 Misión Actual: Hackathon AWS Kiro 
Nuestro objetivo es desarrollar un **Agente SRE impulsado por IA** utilizando AWS Bedrock y el framework Kiro. 

Buscamos transformar la manera en que se monitorean, diagnostican y resuelven las alertas en arquitecturas de microservicios, pasando de la reacción manual a la auto-remediación inteligente mediante *Specs Driven Development* (SDD).

## 🛠️ Nuestro Stack Tecnológico
Dominamos el desarrollo full-stack y el despliegue de infraestructura sólida:

*   **Infraestructura:** AWS (Bedrock, CloudWatch, IAM), Terraform, Docker
*   **Backend & IA:** Python, Agente Kiro
*   **Frontend:** Angular, TypeScript
*   **Metodología:** SDD, Arquitectura Monorepo
